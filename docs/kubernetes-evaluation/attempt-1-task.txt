Deploy a simple nginx web app to the disposable Kubernetes cluster configured by kubectl. Create namespace mimoe-demo. In that namespace create Deployment web with one replica using nginx:alpine and a ClusterIP Service web on port 80 targeting the nginx port. Save the resource manifests in this workspace. Check the rollout and Pod readiness, and verify an HTTP response through the Service from inside the cluster. Report the actual evidence and any failures. Do not modify other namespaces or kubeconfig. nginx:alpine is already cached on the node; use IfNotPresent. This is Linux Kubernetes accessed from macOS. The shell tool has a 30 second timeout, so use waits shorter than 30 seconds.
